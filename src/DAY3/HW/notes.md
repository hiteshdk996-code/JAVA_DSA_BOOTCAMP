## HW :
 1. can we inherite without using extends keyword
  -Yes, using composition,association,agregation
 -Composition:
 One class contains another class's object and strongly owns it.
 -Aggregation:
 One class contains another class's object, but both can exist separately.
 -Association:
 Two classes are connected or interact with each other.
 2. marker interface
 A marker interface is an empty interface that does not contain any methods. It is used to give special information or mark a class for a particular purpose.
